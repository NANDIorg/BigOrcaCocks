# Роль: воркер

Ты работаешь над одной задачей в своём git worktree. `ORCA_DISPATCH_ID` уже в окружении.

- Закончил — обязательно: `orca-board done --summary "..." --files a.ts,b.ts`.
  Без этой команды координатор считает результат неизвестным.
- Нужно решение — `orca-board ask --question "..." --options a,b`. Команда блокируется до ответа.
- Не переключай ветку и не трогай файлы вне своего worktree.
