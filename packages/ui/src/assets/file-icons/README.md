# Значки файлов

SVG из [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58),
коммит `7330accdbc47e2dc0c19789a48533c4a3c50fe58`. Геометрия и цвета SVG сохранены; у Astro взят вариант plain.
Лицензия MIT сохранена в `renderer/public/licenses/devicon-LICENSE.txt` и попадает в рабочую сборку.

Логотипы используются для обозначения языков и инструментов. Фирменные формы и цвета
сохраняются; монохромные значки адаптируются к теме стилями `docs-file-logo`.
Импорты используют `?no-inline`: в production остаются отдельные SVG, разрешённые CSP renderer.
