Архитектура orca-board

docs/architecture.md≈ 18 мин чтенияизменён сегодня в 14:32

Все агенты — дочерние процессы приложения. Никакого API: агент логинится сам. CLI orca-board — тонкий клиент к сокету приложения; его вызывают агенты через свой Bash. Приложение — единственный владелец состояния.

#Процессы

text
Electron main ───── node-pty ───── PTY: claude (координатор)
   │                                   └─ bash: orca-board task-create ...
   │                                          │ unix socket / JSON-RPC
   ├── JSON (tasks, runs, events) ◄───────────┘
   ├── node-pty ───── PTY: claude (воркер задачи #12, worktree ../wt/task-12)
   └── renderer (React): доска + xterm.js на каждый PTY
  • Сокет: $ORCA_SOCKET, иначе ~/.orca-board/orca.sock, на Windows — \\.\pipe\orca-board.
  • Каждый воркер работает в своём git worktree на отдельной ветке orca/<task-id>.

#Модель

Task { id, title, spec, status, deps[], runId?, roleId, agent, worktree?, branch? }

  • status — id колонки доски, не фиксированный enum.
  • runId — прогон, к которому относится задача. Без прогона задача попадает во «Входящие», подробнее — nested-kanban.md.
  • startedAt — первый startDispatch; doneAt — момент попадания в колонку kind=done.

#Роли и колонки

КолонкаkindКто двигает
Бэклогbacklogчеловек, координатор
В работеprogressstartDispatch
Нужен вводinputворкер: orca-board ask
Ревьюreviewворкер: orca-board done
Готовоdoneкоординатор после мержа

Важно. Колонка с kind=done обязана быть ровно одна: по ней считается doneAt и снимается бейдж «в работе» в сайдбаре.

#Прогоны

Глобальная задача = прогон (Run). Координатор создаёт подзадачи через CLI и ждёт событий без трат токенов:

bash
# координатор: завести подзадачу и дождаться результата
orca-board task-create --title "Фикс CSV-экспорта" --role worker
orca-board wait --until done --timeout 1800
  1. Воркер получает задание в PTY и работает в своём worktree.
  2. По orca-board done задача уходит в «Ревью», координатор мержит ветку.
  3. Детектор тишины будит координатора, если воркер в работе молчит дольше порога.

#IPC

Типы — shared/ipc.ts (OrcaApi), мост — preload/index.ts. Документация Electron: contextBridge.

#Открытые вопросы

  • ✓Хранить события в JSONL вместо одного JSON
  • Лимит одновременных воркеров на проект
  • Мерж без координатора для задач-ответов
