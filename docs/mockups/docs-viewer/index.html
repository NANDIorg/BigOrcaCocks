Редизайн окна «Документы»

Три концепции просмотра markdown-файлов проекта. Макеты статичные, но переключаемые: в тёмной полосе сверху каждого — состояния (просмотр, поиск, пусто…). Данные — реальные .md этого репозитория и то, что умеет отдать docs:list (путь, размер, mtime, «новый», группы по задачам).

Документы — вкладка рядом с доской, не модалка. Задачи с изменёнными .md сверху, со статусом-цветом доски.

Общее для всех концепций

  • Новая типографика документа: 15–16px, межстрочный 1.7, строка ≤ 76 знаков, отбивки заголовков, «якоря» у h2/h3, код с языком и кнопкой «Копировать», таблица с рамкой, цитата-предупреждение.
  • Оглавление из заголовков документа, история «Назад/Вперёд» для переходов по ссылкам, поиск в тексте (⌘F).
  • Пустые состояния объясняют, откуда берутся файлы, и дают действие.

Стили — токены из apps/desktop/src/renderer/src/styles.css. Текущее окно — apps/desktop/src/renderer/src/DocsModal.tsx.
