Редизайн вкладки «О проекте»

Три варианта всей вкладки на реальных разделах: проект, агенты, роли, колонки, разрешения, прогоны, дефолт. Макеты статические, но кликабельные: переключение разделов, выезжающая панель, оглавление. Сверху в каждом макете можно сузить окно (1180 / 980) и скрыть список проектов, чтобы проверить узкую ширину.
