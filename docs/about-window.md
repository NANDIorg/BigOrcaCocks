# Окно «О приложении»

Владелец окна — `apps/desktop/src/main/about-window.ts`; документ и ограничение ссылок —
`about-content.ts`. Пункт системного меню вызывает `showAboutWindow()` с главным окном,
растровым `build/icon.png` и реальной версией из `app.getVersion()`.

Окно имеет настоящую рамку Electron. На macOS `hiddenInset` оставляет системные traffic lights
на фоне локального документа; верхняя область служит для перетаскивания. Текст и логотип
выровнены по центру, кнопки открывают GitHub проекта и создание issue в браузере.
Палитра navy/cyan и системный стек шрифтов связывают окно с мастером первого запуска.
Скругление логотипа находится в самом PNG; системные controls не имитируются в HTML.

Это немодальное дочернее окно, без блокировки доски. Повторный вызов возвращает фокус
существующему экземпляру. Escape и ⌘W / Ctrl+W закрывают окно; закрытие возвращает фокус
в видимое главное окно. Закрытие родителя убирает дочернее окно, следующий вызов создаёт
новый экземпляр. Пункт меню восстанавливает главное окно из фонового режима, поэтому
у «О приложении» всегда есть действующий владелец.

Текст поступает из `main/strings/ru.ts` / `en.ts` через `mtIn()` на текущем `mainLocale()`.
`refreshApplicationMenu()` обновляет уже открытый документ через `refreshAboutWindow()`
при смене языка из UI или CLI. Название продукта, автор и адреса проекта не переводятся.
Изменение других настроек не перезагружает документ; обновление языка не забирает фокус
у главного окна.

## Безопасность и доступность

Документ загружается через `data:`. PNG вшит в него как base64: окно не получает доступ
к произвольным локальным файлам. Нет preload, IPC, удалённых ресурсов или renderer-скриптов;
включены sandbox и context isolation, выключены JavaScript, Node integration, webview и DevTools.
CSP запрещает ресурсы по умолчанию, разрешая только локальные стили и встроенное изображение.
Метаданные, включая версию, экранируются перед вставкой в HTML.

Все навигации отменяются. Новые окна запрещены, `shell.openExternal()` получает адрес
только после точного совпадения с `https://github.com/NANDIorg/BigOrcaCocks`
или `https://github.com/NANDIorg/BigOrcaCocks/issues/new`. Запросы, фрагменты,
похожие домены и другие схемы не входят в разрешённый список.

Ссылки имеют нативную семантику и Tab / Enter, видимый фокус, состояния наведения и нажатия.
Первая ссылка получает начальный фокус. Есть локализованные заголовок, `lang` и название
группы ссылок. Reduced motion отключает переходы; forced colors сохраняет системные цвета.
При увеличении масштаба документ прокручивается, ссылки переходят в одну колонку.

Unit tests в `main/about-content.test.ts` проверяют разрешённые адреса, опасные варианты,
экранирование и ru/en. Фокус, клавиатуру, нативную рамку, повторное открытие, смену языка
и закрытие с родителем проверяют отдельно в настоящем Electron.
