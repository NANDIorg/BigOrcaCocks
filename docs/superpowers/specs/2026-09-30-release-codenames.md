# Морские кодовые имена Orca

Каждая серия major/minor `X.Y` получает уникальное английское имя морского животного. Patch наследует имя серии. Исходный реестр: `1.0 — Orca`, `1.1 — Sea Lion` (зарезервировано). Текущая версия приложения остаётся 1.0.1.

Единственный источник — JSON в core. Общее чистое API форматирует версию и название релиза. «О приложении» показывает Orca и версию с кодовым именем; существующие строки версии в обновлениях используют то же API. Неизвестную версию интерфейс показывает без выдуманного имени.

Проверка перед коммитом и CI требует имени текущей серии, запрещает повтор имени независимо от регистра/разделителя, удаление и изменение закреплённых пар. Сравниваются HEAD, база PR/предыдущий push и последний доступный релизный тег-предок. Отсутствие реестра в старых коммитах допустимо при первом внедрении; недоступный commit — ошибка. CI получает полную историю.

Release workflow формирует заголовок `Orca X.Y.Z · Sea Lion` из того же реестра и передаёт его в job черновика. Имена тегов, установщиков и update-манифестов сохраняют SemVer. Исторические опубликованные релизы не редактируются; сейчас готовится код и актуальный PR, выпуск не запускается.

Проверка: core lookup/уникальность/неизменность, настоящий CLI guard на Git-фикстурах, безопасный HTML About, versionLabel, pnpm verify, локальная упаковка и запуск приложения без автоматического UI-прохода.
