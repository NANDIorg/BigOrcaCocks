# Ассистент в боковой панели и авторский значок трея

Панель справа становится полноценным чатом ассистента доски. Диалог не привязан к открытому проекту: агент получает инструкции ассистента, ORCA_SOCKET и ORCA_ROLE=assistant, без ORCA_PROJECT и ORCA_RUN. Существующие настройки агента, модели, усилия и дополнительных инструкций сохраняются.

Claude использует двусторонний stream-json, Codex — app-server, Gemini, Cursor, OpenCode, Copilot и Goose — ACP. Разрешения и вопросы отображаются в чате и требуют явного ответа пользователя. Прерывание останавливает текущий ответ, новый диалог завершает старую сессию. Закрытие панели сохраняет диалог, черновик и положение прокрутки. Штатные правила разрешений CLI не ослабляются.

Пользователь выбрал боковую панель справа и отдельную кнопку терминала для Amp. Amp и произвольный Shell остаются настоящими PTY, но терминал не встраивается в панель чата. Неподдерживаемая версия CLI показывает ошибку и возможность открыть настройки или начать заново, без молчаливой смены агента.

Визуальный язык соответствует DESIGN.md: тёплый графит и существующие четыре темы, спокойная типографика, человеческие сообщения справа, ответы с безопасным Markdown слева. Служебные команды и их результаты скрыты из ленты; карточки разрешений и вопросов остаются явными. Индикатор ожидания с прыгающими точками и мягким шиммером исчезает с первым текстом текущего ответа. Левая граница панели без свечения и тени. Анимации ограничены появлением панели, сообщений и индикатора ответа, учитывают уменьшение движения. Ожидание, разрешения, ошибки и отмена обозначены явно. Enter отправляет, Shift+Enter переносит строку; ввод через IME не отправляет сообщение. Уход вверх по истории отключает автоматическую прокрутку.

Трей использует SVG автора: macOS получает template-маску с Retina-представлением, Windows — многоразмерный цветной ICO, Linux — прозрачный PNG. Исходник сохранён вместе с производными ассетами.

Проверка: реальные тестовые процессы без платных запросов к агентам, сценарии событий/снимков и запросов разрешений, общий pnpm verify, упаковка и запуск .app. Пользователь самостоятельно проверяет интерфейс; автоматического протыкивания экранов нет.
