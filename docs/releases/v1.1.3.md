# Orca 1.1.3 · Sea Lion

Прикладывайте к запросам ИИ документы, логи, код и другие файлы. Подсветка синтаксиса упрощает чтение кода, а индикаторы ассистента помогают следить за работой даже при закрытом чате.

## Что нового

- К целям, задачам, замечаниям и уточнениям теперь можно прикладывать любые файлы, а не только изображения.
- В «Документах» и блоках кода Markdown появилась подсветка синтаксиса с автоматическим определением языка.

## Улучшения

- Файлы в дереве документов, поиске и навигации получили узнаваемые значки языков и форматов.
- Вложения показывают имя и размер; их можно найти в папке, а поддерживаемые форматы — открыть в системном приложении.
- Кнопка закрытого чата показывает работу ассистента, непрочитанный ответ, ожидание пользователя и ошибку.

## Исправления

- Настройки разрешений типа задачи теперь применяются ко всем поддерживаемым CLI-агентам, включая Codex.
- Индикатор работы ассистента больше не исчезает между частями ответа и после выполнения команды до завершения ответа.
- Исправлен запуск Claude Code на Windows при длинном системном запросе и нескольких вложениях.

Полный список изменений: [v1.1.2...v1.1.3](https://github.com/NANDIorg/BigOrcaCocks/compare/v1.1.2...v1.1.3).
