# Orca 1.1.1 · Sea Lion

Воркфлоу получили этапы и проверки под разные задачи. Обновлены окно Windows, карточки обновлений и просмотр вложений.

## Что нового

- **Семь предметных воркфлоу:** программирование, frontend, backend, fullstack, мобильная разработка, автотесты и документация — со своими ролями, подготовкой и независимыми проверками.
- **Актуальные заготовки типов задач:** добавляйте обновлённый вариант через «Настройки → Типы задач → Новый тип», сохраняя свои настроенные типы.
- **Окно Windows:** кнопки окна встроены в интерфейс, а меню приложения поддерживает выбранную тему.

## Улучшения

- Карточки обновлений показывают краткий анонс, полное описание и прогресс скачивания; описание установленной версии доступно без сети.
- Portable-версия объясняет, что обновляется вручную.
- Кнопки левой панели на macOS стали крупнее, а знак Orca внизу панели использует цвет темы.
- Вложения отображаются миниатюрами и открываются на весь экран с удобным переключением изображений.

## Исправления

- Кнопки окон «Документы» и мастера на macOS снова реагируют на нажатия.
- Для модели GPT-6.1 Sol рассчитывается стоимость записанных токенов.

Полный список изменений: [v1.1.0...v1.1.1](https://github.com/NANDIorg/BigOrcaCocks/compare/v1.1.0...v1.1.1).
