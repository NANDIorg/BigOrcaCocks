# Orca Web 2.1.0

Установка Orca Web стала пошаговой и автоматизированной. Мастер помогает безопасно настроить сервер и объясняет каждое решение.

## Что нового

- Закрытый доступ через SSH включён по умолчанию; для публичного HTTPS мастер запрашивает отдельное подтверждение.
- При установке из root обычный пользователь создаётся автоматически; для запуска с полными правами требуется явное согласие.
- Мастер настраивает автозапуск и HTTPS рядом с существующим сайтом, предлагает установить CLI-агенты и заполняет недостающие данные автора Git.
- Повторная настройка позволяет поменять папку проектов и способ доступа с сохранением аккаунтов.

## Улучшения

- Каждый шаг содержит пояснения, а перед применением показан итоговый план.
- Предупреждения требуют подтверждения; перед обновлением и перезапуском работающих заданий нужно явное согласие.

## Исправления

- При ошибке автоматической настройки восстанавливаются прежние настройки и состояние сервисов.
- Повторный запуск продолжает прерванную установку и сохраняет пользователя сервиса.
