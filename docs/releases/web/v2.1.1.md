# Orca Web 2.1.1

Orca Web снова обнаруживает установленные агенты при первом запуске. Установщик и серверные команды получили сдержанное монохромное оформление, которое удобнее читать в терминале.

## Улучшения

- Этапы установки разделены рамками и индикатором прогресса; параметры выбираются стрелками, а итоговый план показывается перед применением.
- Справка `orca-web help` показывает команды вертикальным списком с описаниями и примерами; доступны `--help`, `-h`, `--version` и `-v`.
- Вывод `status` и `doctor` структурирован, а длинные строки установщика подстраиваются под ширину терминала.

## Исправления

- Установленные Claude Code и Codex отображаются в мастере знакомства до выбора проекта.
- Ctrl+C корректно отменяет ввод в установщике, а отмена повторной настройки сохраняет существующие аккаунты и конфигурацию.
- Неизвестные флаги и лишние аргументы отклоняются до запуска команды или изменения настроек.

Полный список изменений: https://github.com/NANDIorg/BigOrcaCocks/compare/web/v2.1.0...web/v2.1.1
