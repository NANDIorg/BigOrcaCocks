# Orca Web 2.0.1

Orca Web теперь можно установить и запустить под root. Установщик и приложение
предупреждают о полных правах доступа к серверу и продолжают работу.

## Исправления

- Установка, мастер настройки, запуск сервиса и обновления больше не требуют создания отдельного системного пользователя.
- При работе под root системные команды выполняются напрямую, поэтому sudo не требуется.

Полный список изменений: https://github.com/NANDIorg/BigOrcaCocks/compare/web/v2.0.0...web/v2.0.1
