# Orca Web 2.0.0

Orca теперь можно установить на свой Linux-сервер и работать с проектами и агентами через браузер.

## Что нового

- Веб-интерфейс с привычной доской задач, чатами, терминалами и настройками Orca.
- Вход по логину и паролю для одного или двух пользователей; проекты и агенты работают на сервере.
- Установщик и мастер настройки серверной версии с HTTPS.
- Проверка, скачивание и установка обновлений прямо из браузера с резервной копией и восстановлением при сбое.
- Загрузка и скачивание файлов, просмотр документов и предпросмотр проектов.

## Улучшения

- Сессия восстанавливается после переподключения, а управление общим терминалом можно передавать между вкладками.
- Web получает собственные выпуски и обновляется независимо от Desktop.
