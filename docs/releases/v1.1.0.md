# Orca 1.1.0 · Sea Lion

Новый интерфейс Orca, полноценный чат ассистента и просмотр результатов работы агентов
прямо в приложении. В этой версии также появились дерево файлов проекта, экспорт типов
задач и восстановление остановленного мержа.

## Новое

- **Оформление всего приложения.** Четыре спокойные темы: Graphite, Slate, Forest и
  светлая Paper. Graphite остаётся темой по умолчанию. В настройках можно уменьшить
  анимации; оформление применяется к доске, документам, настройкам и служебным окнам.
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)
- **Мастер первого запуска.** Четыре шага знакомят с Orca, помогают выбрать первоначальные
  настройки, показывают обнаруженные CLI-агенты и предлагают добавить первый репозиторий.
  Каждый этап сопровождает отдельная анимированная иллюстрация.
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)
- **Чат ассистента справа.** Потоковые ответы, Markdown, копирование сообщений,
  остановка ответа, вопросы с выбором и карточки разрешений. Вместо длинных результатов
  команд и служебного JSON видны краткие действия и их статус. Настройки ассистента
  находятся в общих настройках приложения: агент, модель, effort и инструкции.
  [#26](https://github.com/NANDIorg/BigOrcaCocks/pull/26),
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)
- **Системная оболочка.** Авторский логотип приложения и трея, меню с привычными
  командами и горячими клавишами, обновлённое окно «О приложении». На macOS системные
  кнопки окна встроены в интерфейс без отдельной полосы заголовка. Главные кнопки
  приведены к общему стилю, в настройках оставлена одна кнопка закрытия.
  [#28](https://github.com/NANDIorg/BigOrcaCocks/pull/28),
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)
- **Просмотр результатов агентов.** HTML-макеты, изображения и Markdown можно открыть
  в просмотрщике и принять или вернуть работу из него. Есть дерево результатов по
  подзадачам и ширина просмотра «Десктоп / Планшет / Телефон». Снимок файлов сохраняется
  после мержа; интернет-ресурсы HTML включаются отдельно и по умолчанию выключены.
  [#22](https://github.com/NANDIorg/BigOrcaCocks/pull/22)
- **Вкладка «Файлы».** Дерево каталога проекта с управлением с клавиатуры, обновлением,
  копированием пути и показом файла в системном файловом менеджере. Markdown можно
  открыть в «Документах». Служебные и игнорируемые Git файлы скрыты; дерево только для чтения.
  [#27](https://github.com/NANDIorg/BigOrcaCocks/pull/27)
- **Выбор исполнителя этапа.** В редакторе воркфлоу видны агент, модель и состояние роли;
  отдельно выбираются автоматическое назначение координатором и ограничение выбранными ролями.
  [#23](https://github.com/NANDIorg/BigOrcaCocks/pull/23)
- **Экспорт типа задач.** Кнопка «Экспорт» сохраняет тип в один JSON-файл: роли,
  воркфлоу, правила и режим разрешений. Экспортируется сохранённая версия типа.
  [#32](https://github.com/NANDIorg/BigOrcaCocks/pull/32)
- **Флаги запуска агентов.** Свои параметры CLI можно указать у роли и ассистента.
  Они применяются со следующего запуска; ошибки разбора и конфликты со служебными
  флагами показаны в настройках.
  [#33](https://github.com/NANDIorg/BigOrcaCocks/pull/33)
- **Морские кодовые имена.** Серия 1.1 получает имя Sea Lion: оно показывается рядом
  с версией в «О приложении» и сохраняется у будущих patch-релизов 1.1.x. Новые серии
  получают уникальное животное.
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)
- **Обновлённая документация.** README с логотипом и схемой работы объясняет, как
  задачи, координатор, агенты и проверка результата связаны между собой.
  [#24](https://github.com/NANDIorg/BigOrcaCocks/pull/24)

## Исправления

- **Остановленный мерж больше не выглядит как обычное ревью.** Показаны причина
  остановки и действия «Повторить мерж» / «Вернуть в работу». После перезапуска
  приложение подбирает прерванные этапы.
  [#31](https://github.com/NANDIorg/BigOrcaCocks/pull/31)
- **Репозиторий без коммитов.** Вместо сырой ошибки Git появляется диалог создания
  первого коммита. После подтверждения запуск повторяется; без согласия человека
  файлы не коммитятся. При отсутствии целевой ветки мерж не удаляет ветку агента.
  [#30](https://github.com/NANDIorg/BigOrcaCocks/pull/30)
- **Читаемые выпадающие списки на Windows.** Фон и текст используют цвета выбранной темы.
  [#25](https://github.com/NANDIorg/BigOrcaCocks/pull/25),
  [#29](https://github.com/NANDIorg/BigOrcaCocks/pull/29)

## Обновление и ограничения

- При обновлении с 1.0.1 настройки ассистента из типа задач по умолчанию автоматически
  переносятся в «Настройки → Ассистент». Уже заданные общие настройки имеют приоритет.
- Чат требует установленного и авторизованного CLI совместимой версии. Поддерживаются
  Claude, Codex, Gemini, Cursor, OpenCode, Copilot и Goose. Для Amp и Shell предусмотрена
  отдельная кнопка открытия терминала. Флаги запуска должны поддерживаться чат-режимом CLI.
- Закрытие панели сохраняет переписку и черновик в текущей сессии приложения.
  Отдельного сохранения истории чата на диск нет; лента ограничена 300 сообщениями.
- Экспортированный тип задач пока нельзя импортировать через интерфейс. Несохранённые
  изменения редактора в экспорт не входят; перед передачей JSON проверьте содержащиеся
  в правилах и промптах внутренние данные.
- Дерево файлов ограничено 5000 записями на папку и не раскрывает символические ссылки.
  Причины остановки этапов могут оставаться на русском в английском интерфейсе.
- **macOS arm64/x64:** DMG для установки и ZIP для автообновления. Релизная цепочка
  требует Developer ID, notarization и stapling приложения и DMG; ошибка проверки
  останавливает сборку. Обычное системное подтверждение первого открытия допустимо.
- **Windows x64:** NSIS-установщик и portable, без подписи кода; возможен SmartScreen.
  Linux-установщик не выпускается.
- Фактические результаты подписи, проверки скачанных установщиков и ограничения
  ручной приёмки фиксируются в описании черновика после сборки. До публикации
  сквозное автообновление с предыдущего релиза остаётся непроверенным.

Полный список изменений: [v1.0.1...v1.1.0](https://github.com/NANDIorg/BigOrcaCocks/compare/v1.0.1...v1.1.0).
