# Orca 2.0.0 · Sea Otter

История ассистента теперь сохраняется после перезапуска, а работа с долгими задачами стала надёжнее. Привычные доски, роли и настройки сохранены.

## Что нового

- Сохранённую историю чата ассистента можно просмотреть после перезапуска; новую работу начинают в отдельном диалоге.

## Улучшения

- Долгие Git-операции выполняются в фоне, позволяя продолжать работу с доской.
- После отмены задачи или смены этапа запоздалый результат операции не меняет уже другую работу.
- Резервные копии приложения включают сохранённые диалоги ассистента.

## Исправления

- Повторная команда выхода больше не прерывает завершение работающих процессов и сохранение состояния.
- Исправлена обработка разных записей одного и того же пути Windows при восстановлении рабочих каталогов.

Полный список изменений: [v1.1.3...v2.0.0](https://github.com/NANDIorg/BigOrcaCocks/compare/v1.1.3...v2.0.0).
