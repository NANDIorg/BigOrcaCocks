# orca-board 1.0.1

Первый выпуск с подписанной сборкой для macOS: приложение подписано Developer ID и
нотаризовано Apple, поэтому устанавливается без обхода Gatekeeper. Кроме того, у каждой
глобальной задачи теперь свой граф воркфлоу и своя git-ветка, появились нода «Решение ИИ»,
картинки в замечаниях и ассистент, который умеет менять настройки.

## Новое

- **Воркфлоу на уровне глобальной задачи.** Граф ведёт вся глобальная задача: этапы «Работа»,
  проверки, решения человека, мерж. Подзадача внутри «Работы» может идти своим путём (проверка
  или решение человека перед слиянием). Появилась библиотека шаблонов нод. Графы типов задач
  от 1.0.0 обновляются автоматически при загрузке.
  [#11](https://github.com/NANDIorg/BigOrcaCocks/pull/11)
- **Нода «Решение ИИ».** Развилку графа выбирает агент: он отвечает на вопрос по смыслу задачи
  и выбирает один из вариантов. Если агент не смог выбрать, решение уходит человеку в Инбокс.
  [#12](https://github.com/NANDIorg/BigOrcaCocks/pull/12)
- **Нода «Git».** Приложение само создаёт ветку, переключается, коммитит или пушит и идёт
  дальше по исходу `ok` или `error`. [#5](https://github.com/NANDIorg/BigOrcaCocks/pull/5)
- **Своя ветка на каждую глобальную задачу.** Подзадачи сливаются в ветку
  `feature/<runId>-<slug>` в отдельном worktree, а не в ветку, открытую в проекте. Несколько
  глобальных задач идут параллельно и не смешиваются. Имя ветки показано в шапке задачи.
  [#2](https://github.com/NANDIorg/BigOrcaCocks/pull/2),
  [#9](https://github.com/NANDIorg/BigOrcaCocks/pull/9)
- **Git корня проекта в шапке.** Бейдж текущей ветки превратился в меню: fetch, pull
  (только fast-forward), список веток с поиском и переключение ветки с защитой от живых агентов
  и незакоммиченных правок. [#3](https://github.com/NANDIorg/BigOrcaCocks/pull/3),
  [#6](https://github.com/NANDIorg/BigOrcaCocks/pull/6)
- **Группы проектов** в левом меню: создать, переименовать, свернуть, переставить.
  [#4](https://github.com/NANDIorg/BigOrcaCocks/pull/4)
- **Картинки.** Скриншоты и макеты можно приложить при создании глобальной задачи и при
  возврате работы агенту (вставка из буфера, drag&drop, кнопка). Агенты получают их вместе с
  замечаниями. [#13](https://github.com/NANDIorg/BigOrcaCocks/pull/13),
  [#14](https://github.com/NANDIorg/BigOrcaCocks/pull/14)
- **Ассистент доски.** Панель ассистента стала чатом поверх терминала (переключатель
  «Чат / Терминал»). Ассистент может менять все настройки приложения и проекта через CLI;
  опасные операции, включая смену агента роли, требуют явного подтверждения.
  [#15](https://github.com/NANDIorg/BigOrcaCocks/pull/15)
- **Редизайн воркфлоу.** На экране глобальной задачи появилась вкладка «Граф»: пройденные
  этапы, текущий этап и возвраты. Редактор графа разделён на три колонки: палитра, холст с
  панелью «Проблемы» и инспектор. [#16](https://github.com/NANDIorg/BigOrcaCocks/pull/16)
- **Окно настроек** одного размера на всех вкладках и режим «на весь экран».
  [#17](https://github.com/NANDIorg/BigOrcaCocks/pull/17)

## Исправления

- Установщик macOS больше не блокируется Gatekeeper: сборки arm64 и x64 подписаны Developer ID
  с hardened runtime, приложение и DMG нотаризованы, тикеты вшиты (stapled).
  [#7](https://github.com/NANDIorg/BigOrcaCocks/pull/7)
- Установленное приложение, запущенное из терминала рядом с `pnpm dev`, больше не открывает
  интерфейс с чужого dev-сервера: упакованная сборка игнорирует `ELECTRON_RENDERER_URL`.
  [#18](https://github.com/NANDIorg/BigOrcaCocks/pull/18)

## Обновление и ограничения

- **macOS** (Apple Silicon и Intel): DMG для установки, ZIP для автообновления. Сборки
  подписаны Developer ID и нотаризованы. Версия 1.0.0 была подписана только ad-hoc. Если
  автообновление с неё не сработает, скачайте DMG вручную.
- **Windows** x64: установщик NSIS и portable-версия, **без подписи кода**. SmartScreen может
  предупредить о неизвестном издателе.
- Linux-сборки нет.
- Данные 1.0.0 переносятся автоматически при первом запуске: графы типов задач переводятся на
  воркфлоу глобальной задачи, старые настройки раздела «Git» удаляются. Прогоны, начатые в 1.0.0,
  доводятся до конца по-старому.
- Раздел «О проекте → Git» (автоматический push ветки, защищённые ветки) убран: что делать с
  веткой глобальной задачи дальше, решает пользователь.
