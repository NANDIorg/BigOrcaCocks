# Редактор воркфлоу («Настройки → Типы задач → Воркфлоу») — макеты рестайлинга

Сейчас (`settings/TaskTypeWorkflow.tsx`, `WorkflowCanvas.tsx`, `WorkflowInspector.tsx`, `WorkflowTemplateBlock.tsx`):
палитра — ряд иконок без подписей; «Свои ноды» — отдельная панель; ошибки видны только цветом рамки и в `<title>`;
легенда типов спрятана в `<details>` инспектора; инспектор — плоский список `<fieldset>`; путь подзадачи — незаметный
select; экран — плоский стек блоков.

Макеты статичные, открываются без сборки. Кликабельны ноды холста (инспектор меняется: «Реализация» — путь подзадачи,
«Ревью» — ошибка «не выбрана роль проверяющего», «Проверка человеком» — предупреждение «возврат без лимита»), список
проблем, переключатели ширины (1440 / 860) и темы. Параметры в адресе: `?w=narrow&theme=light`.
Цвета и классы — из `styles.css` (`wf-node--*`, `wf-port--*`, `wf-edge--*`, `--wf-accept`, `--wf-reject`).

Общее у обоих вариантов:
- палитра с подписями и одной строкой пояснения (тексты — `wf.help.*.summary`), сгруппирована: Агенты / Человек /
  Приложение / Начало и конец; «Свои ноды» — часть палитры;
- на ноде с проблемой — значок «!» и текст проблемы прямо на холсте, не только цвет рамки; у ноды — цветная полоса типа;
- инспектор — карточки-секции: «Основное», «Кто выполняет», «Что сделать», «Путь подзадачи», «Куда ведёт», «Своя нода»;
  у карточки с проблемой — точка и рамка цвета проблемы, у поля — текст ошибки под ним;
- путь подзадачи — отдельная карточка с миниатюрой пути, переключателем «По умолчанию / Свой путь» и кнопкой «Открыть путь»;
- «Сохранить» недоступна при ошибках и говорит почему.

## Вариант A — три колонки (`variant-a.html`)

Экран — три секции: закреплённая полоса статуса (свой граф, не сохранено, «1 ошибка», «1 предупреждение» — кликабельны,
«Отменить», «Сохранить»), «Граф этапов» и «Файл графа» (экспорт/импорт, лимит повторов, сброс). Редактор — палитра слева
(поиск, группы, «Свои ноды» с «+ Сохранить выбранную ноду»; внизу — цвета переходов, палитра служит легендой), холст
по центру с панелью «Проблемы» под ним (клик — к ноде), инспектор справа — все карточки раскрыты.
Узкое окно: палитра становится горизонтальной лентой над холстом, инспектор уходит под холст.

Плюсы: всё видно сразу, палитра сама по себе легенда; ближе всего к текущей раскладке `wf-editor` — меньше переделки.
Минусы: холст узкий (три колонки делят ширину), граф приходится уменьшать; длинный инспектор с раскрытыми карточками.

## Вариант B — холст во всю ширину (`variant-b.html`)

Палитра — панель инструментов над холстом: подписанные кнопки по группам и меню «Свои ноды ▾» в той же панели.
Под ней — баннер проблем с листанием «‹ 1 из 2 ›» и «Показать». На холсте — выноски над нодами с текстом проблемы,
у нод «Работа» — полоска «путь: Работа › Мерж › Конец». Внизу холста — легенда, видна всегда. Инспектор — аккордеон:
свёрнутая карточка показывает сводку («Куда ведёт: принять → Проверка»), карточки с проблемами и «Путь подзадачи»
раскрыты. Файл графа и сброс — в свёрнутом «Файл графа и сброс».

Плюсы: больше места холсту; проблемы и путь подзадачи заметны прямо на графе; инспектор короткий.
Минусы: панель инструментов на узком окне в две строки; выноски над нодами могут перекрывать соседние переходы
на плотном графе; больше новой вёрстки (меню, баннер, аккордеон).

## Рекомендация

**B**. Главное в редакторе — холст, а в A он самый узкий. B решает все пункты задачи и делает ошибки и путь подзадачи
видимыми там, где на них смотрят, — на графе. Из A стоит взять полосу статуса с кликабельными счётчиками и панель
«Проблемы» — как раскрытие баннера B, когда проблем больше трёх.

## Открыто для решения

- Выноски над нодами (B) или плашки под нодами (A) — на плотных графах плашки меньше перекрывают переходы.
- Раскрывать ли в аккордеоне B по умолчанию все карточки у новой ноды.
- Оставлять ли полоску пути на ноде «Работа» с путём по умолчанию или только со своим путём.
