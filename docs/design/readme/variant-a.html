Как это работает

  1. Добавьте git-репозиторий кнопкой «+» в сайдбаре и нажмите «Координатор» — откроется Claude Code с инструкцией и целью.
  2. Координатор раскладывает цель на задачи. Старт задачи создаёт отдельный git worktree и запускает в нём агента — каждый работает на своей ветке orca/‹id›.
  3. Воркер сдаёт результат явно — orca-board done. Вы смотрите diff на карточке и нажимаете «Слить и закрыть» или «Доработать» с замечаниями.

Возможности

Канбан-доска
Колонки от «Бэклога» до «Сделано», настраиваются в «О проекте».		Worktree на задачу
Агенты изолированы друг от друга и от вашего дерева.		Роли
Агент и модель под тип задачи: claude, codex и др.
Терминалы
PTY с агентом на каждую задачу, клик по карточке.		Вопросы и ревью
Ответ воркеру и приём результата — на карточке.		Работа в фоне
Иконка в строке меню или трее; агенты не останавливаются.

Установка

macOS

  1. Скачайте orca-board-‹версия›-arm64.dmg (Apple Silicon) или -x64.dmg (Intel) из Releases.
  2. Перетащите orca-board.app в «Программы» и откройте.
  3. Нужны git и хотя бы один CLI-агент — claude (Claude Code с подпиской), codex и др.

Windows3

Установщик orca-board-‹версия›-x64.exe или portable-вариант из Releases.

Windows

Сборка не подписана и на живой Windows пока не проверялась — при первом запуске SmartScreen попросит подтверждение. О проблемах пишите в issues.

Из исходников

pnpm install --frozen-lockfile
pnpm dev

Нужны Node.js 24, pnpm и git. Процесс разработки — CONTRIBUTING.md.
