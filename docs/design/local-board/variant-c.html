Что видно на макете

  • Колонки — ноды воркфлоу типа глобальной задачи (Task.stage.nodeId): видно, на каком шаге конвейера каждая подзадача и где скапливается работа.
  • Состояние внутри этапа — цветной бейдж («работает 12:34», «вопрос», «упал», «ждёт: …»), а не колонка. Возврат с ревью — «заход 2» с причиной.
  • Гейт «Ревью кода» — строка внутри карточки рабочей задачи, отдельной карточки ревьюера нет.
  • Задачи-ответы вне графа — своей дорожкой. «Готово» — облегчённые строки.
  • Наведите или сфокусируйте карточку в «Очереди» (например, «Changelog») — подсветится цепочка зависимостей.
  • Перетаскивания между этапами нет: этапы двигает воркфлоу. Ручная смена статуса — из меню карточки, классический вид — переключателем «по статусам».
