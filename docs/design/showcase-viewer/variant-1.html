1. Просмотрщик показа

Модалка по образцу .modal.inbox-full. Файлы — вкладки под шапкой (подзадачи — пилюли над ними), управление — отдельной строкой: ширина · обновить · интернет-ресурсы слева, «Открыть в браузере» · «В папке» справа. Снизу — строка статуса: изоляция, масштаб, путь. Проверьте: переключатели ширины, вкладки, ←/→, Esc, «Интернет-ресурсы» на variant-b.html, баннер на variant-c.html.

2. Inline-превью в карточке approval

Approval в панели Инбокса (460 px — минимальная ширина: окно приложения не уже 860 px). У HTML-файла — «Превью» и «На весь экран», остальное — в «⋯». Нажимайте кнопки: превью раскрывается, «На весь экран» открывает просмотрщик поверх страницы (Esc — назад).

    3. Несколько подзадач в одном approval

    Approval уровня прогона: показ нескольких подзадач сразу. Показ сгруппирован по подзадачам — заголовок (свернуть, статус, «Смотреть») и её файлы.

      4. Состояния

      Одни и те же состояния во всех вариантах — меняется только оболочка вокруг. Слева — тело просмотрщика, под плиткой — что доступно. Любое можно включить в живом просмотрщике (раздел 1, «Показать состояние»).

      Те же состояния в карточке Инбокса

      Сверху вниз: загрузка превью, старое приложение, файл не найден, тип не открывается. Тексты — прежние (showcase.stale, showcase.cantOpen), новые — по-русски и в en через i18n.
